# Justitieministeriets beslut om upphävande av justitieministeriets beslut om formulären för blanketter för kandidatuppställning vid allmänna val

*112/2020*

Genom detta beslut upphävs justitieministeriets beslut om formulären för blanketter för kandidatuppställning vid allmänna val (313/2014).

Detta beslut träder i kraft den 1 april 2020.
