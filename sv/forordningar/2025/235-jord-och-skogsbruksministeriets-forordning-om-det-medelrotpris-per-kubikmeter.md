# Jord- och skogsbruksministeriets förordning om det medelrotpris per kubikmeter virke som ska användas vid beräkning av vissa stöd inom incitamentsystemet för skogsbruket

*235/2025*

I enlighet med jord- och skogsbruksministeriets beslut föreskrivs med stöd av 11 § i lagen om ett temporärt incitamentsystem för skogsbruket (71/2023):

## 1 § Medelrotpris per kubikmeter virke

Vid beräkning av miljöstöd för skogsbruket och ersättning för trädbestånd vid hyggesbränning används medelrotpriser för områden som bestämts utifrån landskapsindelningen enligt följande:

| *Landskap* | *Medelrotpris, euro* |
|---|---|
| Nyland | 50,71 |
| Egentliga Finland | 52,33 |
| Satakunta | 53,57 |
| Egentliga Tavastland | 54,86 |
| Birkaland | 54,14 |
| Päijänne-Tavastland | 56,02 |
| Kymmenedalen | 53,15 |
| Södra Karelen | 52,57 |
| Södra Savolax | 53,58 |
| Norra Savolax | 49,72 |
| Norra Karelen | 46,97 |
| Mellersta Finland | 51,58 |
| Södra Österbotten | 47,68 |
| Österbotten | 42,53 |
| Mellersta Österbotten | 44,11 |
| Norra Österbotten | 40,13 |
| Kajanaland | 37,69 |
| Lappland | 34,49 |

## 2 § Ikraftträdande

Denna förordning träder i kraft den 1 juni 2025. Denna förordning tillämpas på ansökningar om miljöstöd som har anhängiggjorts den 1 juni 2025 eller senare.

Genom denna förordning upphävs jord- och skogsbruksministeriets förordning om det medelrotpris per kubikmeter virke som ska användas vid beräkning av vissa stöd inom incitamentsystemet för skogsbruket (1222/2023).
