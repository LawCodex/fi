# Jord- och skogsbruksministeriets förordning om det medelrotpris per kubikmeter virke som ska användas vid beräkning av miljöstödet för skogsbruket

*1068/2022*

I enlighet med jord- och skogsbruksministeriets förordning föreskrivs med stöd av 10 § i den temporära lagen om finansiering av hållbart skogsbruk, sådan den lyder i lag 227/2016:

## 1 § Medelrotpris per kubikmeter virke

Vid beräkning av miljöstödet för skogsbruket används medelrotpriser för områden som bestämts utifrån landskapsindelningen enligt följande:

| *Landskap* | *Medelrotpris* |
|---|---|
| Nyland | 38,56 € |
| Egentliga Finland | 41,05 € |
| Satakunta | 41,26 € |
| Egentliga Tavastland | 43,20 € |
| Birkaland | 41,19 € |
| Päijänne-Tavastland | 43,72 € |
| Kymmenedalen | 40,64 € |
| Södra Karelen | 39,86 € |
| Södra Savolax | 40,36 € |
| Norra Savolax | 35,99 € |
| Norra Karelen | 33,14 € |
| Mellersta Finland | 39,42 € |
| Södra Österbotten | 36,97 € |
| Österbotten | 33,16 € |
| Mellersta Österbotten | 33,45 € |
| Norra Österbotten | 29,90 € |
| Kajanaland | 27,65 € |
| Lappland | 27,12 € |

## 2 § Ikraftträdande

Denna förordning träder i kraft den 1 januari 2023. Denna förordning tillämpas på ansökningar om miljöstöd som har anhängiggjorts den 1 januari 2023 eller senare.
